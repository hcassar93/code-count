# Code Count

A Hammerspoon project for code counting functionality using `cloc` (Count Lines of Code).

## Prerequisites

This project requires `cloc` to be installed on your system:

```bash
brew install cloc
```

## Installation

1. Make sure you have [Hammerspoon](http://www.hammerspoon.org/) installed
2. Install `cloc` via Homebrew: `brew install cloc`
3. Clone this repository
4. Symlink or copy the `init.lua` file to your Hammerspoon configuration directory
5. Reload Hammerspoon configuration

## Usage

Configure and customize the functionality in `init.lua` as needed.

## Configuration

Edit `init.lua` to customize the behavior according to your needs.
